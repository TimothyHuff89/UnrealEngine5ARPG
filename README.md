# Top-Down Action RPG

A top-down action RPG currently in development using Unreal Engine 5.
This project is an independent game-development project focused on building
gameplay systems and applying software-development concepts in Unreal Engine.

## Current Features

- Click-to-move player controls
- Mouse-based aiming
- Projectile combat
- Enemy pursuit behavior
- Enemy attack distance and cooldown systems
- Player and enemy health/damage systems
- Player death and respawning
- Collision handling
- Character animation integration

## Technologies

- Unreal Engine 5
- Blueprint Visual Scripting
- Git and GitHub

## Project Status

This project is currently in development. Additional gameplay systems,
weapons, enemies, animations, and other features are planned as development
continues.
